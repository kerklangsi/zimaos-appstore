# GitHub Actions Latest Version Rule

Whenever adding, updating, or referencing any GitHub Actions (e.g., `actions/checkout`, `actions/setup-python`, `actions/setup-node`, `actions/configure-pages`, `actions/deploy-pages`), **ALWAYS search online first** via web search or GitHub releases to discover and use the exact latest available release version tag. Never guess or hardcode version numbers without verifying the latest online release first.
